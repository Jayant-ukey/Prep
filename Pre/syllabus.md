## 💻 2. Mains Exam (Professional Knowledge – IT)

This is the most important section for IT Officer.

### 🔹 Core IT Topics

* **Data Structures**

  * Arrays, Linked Lists, Stacks, Queues, Trees, Graphs
* **Database Management Systems (DBMS)**

  * SQL, Normalization, Transactions, ER Models
* **Operating Systems**

  * Process Management, Memory Management, Deadlocks
* **Computer Networks**

  * OSI Model, TCP/IP, Routing, DNS, HTTP/HTTPS
* **Software Engineering**

  * SDLC, Testing, Agile, Waterfall model
* **Object-Oriented Programming (OOPs)**

  * Concepts like Inheritance, Polymorphism, Encapsulation
* **Cyber Security**

  * Encryption, Firewalls, Malware, Network Security basics

### 🔹 Programming Knowledge

* Basics of C, C++, Java, Python
* Algorithms & Complexity

### 🔹 Other Important Topics

* Cloud Computing
* Artificial Intelligence basics
* Data Analytics basics
* Web Technologies (HTML, CSS, JavaScript)
