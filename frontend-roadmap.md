## 🚀 1. Modern JavaScript (ES6+)
Do not study all of JavaScript. Interviewers look for your ability to handle asynchronous data and modern syntax fluently. [1, 2] 

* Variables & Scope: Difference between let, const, and var; understanding block scope and hoisting.
* Arrow Functions: Syntax, implicit returns, and how this behaves differently from regular functions.
* Destructuring & Rest/Spread: Extracting data from objects/arrays; copying or merging objects using ....
* Array Methods: Complete mastery of .map(), .filter(), and .reduce() (expect live coding challenges on these).
* Asynchronous JS: How Promises work, handling API errors, and writing clean asynchronous code using async/await.
* The Event Loop: How JavaScript handles concurrent tasks (understanding the Call Stack, Microtask Queue, and Callback Queue). [3, 4, 5, 6, 7] 

------------------------------
## 🛡️ 2. TypeScript
Since you already know Java, TypeScript will feel natural. Focus on how it enforces types on top of JavaScript.

* Basic Types: Declaring types for primitives (string, number, boolean, any, unknown).
* Interfaces vs. Types: Defining object shapes and knowing when to use interface vs type.
* Functions: Typing function arguments, return values, and defining optional parameters (?).
* Generics: Writing reusable components and functions with dynamic types (very similar to Java Generics).
* Union & Intersection Types: Combining types using | (e.g., string | number) and &.
* Type Assertions & Guards: Forcing a type using as or narrowing down types at runtime using typeof or instanceof. [8, 9, 10, 11, 12] 

------------------------------
## ⚛️ 3. React
Focus entirely on Functional Components. Do not waste time learning old Class Components unless a specific job description requires maintenance work. [13] 

* JSX & Rendering: Rules of JSX, rendering lists using .map(), and why a unique key prop is mandatory.
* Props & State: Passing data down to components (Props) vs managing local component data (useState).
* The Component Lifecycle: Fetching data and cleanup operations using the useEffect hook.
* Performance Hooks: Optimising renders and caching functions/values using useMemo and useCallback.
* Form Handling: Controlled components (binding inputs to React state) and tracking changes.
* Context API: Passing global state down the component tree without "prop drilling". [14, 15, 16, 17, 18] 

------------------------------
## 🎨 4. CSS Layouts
Interviewers do not care if you can design beautiful graphics, but you must know how to structure an application layout instantly.

* The Box Model: Complete understanding of content, padding, border, and margin.
* Flexbox (One-Dimensional): Aligning items horizontally or vertically using flex-direction, justify-content, and align-items.
* CSS Grid (Two-Dimensional): Creating rows and columns using grid-template-columns and gap.
* Centering Elements: Knowing the absolute fastest ways to center a div both horizontally and vertically (e.g., display: grid; place-items: center;).
* Responsive Design: Using Media Queries or mobile-first design principles to make a UI look good on both phones and desktops. [19, 20, 21, 22, 23]
